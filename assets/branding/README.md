# First Settlement thumbnail

`first-settlement.png` is the square illustrated game thumbnail and Godot project
icon. The macOS export preset also uses it for future app builds. Existing
installed apps and published downloads require rebuilding to receive the icon.
Windows executable resource modification remains disabled in its existing preset.

Generated with the built-in imagegen tool on 2026-11-16. This is illustrative
cover art, not a gameplay screenshot.

## Original generation prompt

Use case: stylized-concept. Create a polished square game thumbnail / desktop app icon for an original ancient settlement strategy game, Civilization — First Settlement. No text or lettering. A beautifully composed miniature ancient riverside settlement: one prominent humble timber and golden thatch house, two smaller reed huts, a small cultivated field, oak trees, winding blue river and distant soft hills. Elevated three-quarter isometric view, cohesive painterly 3D illustration, grounded natural materials, rich forest green and warm amber sunlight at dawn, inviting sense of beginnings and discovery. Strong clear central silhouette legible at tiny icon sizes, few large clean shapes, refined detail concentrated on the central house, subtle atmospheric depth. Full bleed square composition, opaque background, keep main house and settlement within central 75 percent so it crops well for app icons. No modern buildings, castles, crowns, UI, hex grid, border, logos or watermark.
